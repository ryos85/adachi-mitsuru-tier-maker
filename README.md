# あだち充 作品Tierメーカー

あだち充作品を `S / A / B / C / 未読` に分類できる、非公式のファンメイドTier表です。

## 使い方

- PC：表紙をドラッグして各Tierへ移動します。
- スマートフォン：表紙をタップしてから移動先の段をタップします。
- Tier名は直接編集できます。
- 「クリップボードにコピー」で完成したTier表を画像としてコピーできます。
